열두동물 한글 수비대 — Typecast AI 녹음 키트 (Windows)
=====================================================

이 키트는 게임 대사 599줄(동화책 1·2, 사건 수사대 12개, 글자 소리)을 Typecast AI 목소리로
한 줄씩 MP3로 만듭니다. 파일 이름은 대본(docs/dubbing_*.csv)의 파일명 그대로라서, 만든 파일을
Claude에게 주면 바로 게임에 연결됩니다.

※ 이 키트를 실행하기 전까지는 음성 파일이 하나도 없습니다. 게임은 지금처럼 기기 목소리로 읽습니다.

필요한 것
---------
- Windows 10 또는 11 PC (PowerShell은 Windows에 기본으로 있어요)
- Typecast API 키: https://studio.typecast.ai/developers/api 에 로그인 → API 키 만들기 → 복사
  · API 요금제는 Typecast 웹 구독과 따로입니다.
  · 무료(Free) 요금제: 한 달 15,000 크레딧(1글자 = 1크레딧). 이 키트의 전체 대사는 약 13,900자라
    한 번은 무료로 만들 수 있어요. 다만 무료 음성은 상업적으로 쓸 수 없고 출처 표기가 필요합니다
    (집에서 아이와 쓰는 용도. 게임 설정 화면에 "AI 음성: Typecast"를 넣어 둡니다).
  · 목소리를 바꿔 여러 번 다시 만들면 크레딧이 모자랄 수 있어요. 그때는 다음 달에 이어서 하거나
    Lite 요금제(월 15달러, 200,000 크레딧)를 쓰면 됩니다.

순서 (파일을 두 번 클릭)
------------------------
0) ZIP을 풀고, key.txt를 메모장으로 열어 안내 문구를 지우고 API 키만 붙여 넣은 뒤 저장합니다.
   (키는 대화창이나 다른 사람에게 보내지 마세요.)
1) 1_voices.bat
   Typecast 목소리 목록을 받고, 역할 29개(내레이터, 거북이 스승님, 영웅 12명, 사건 친구, 악당,
   동화 속 인물)에 어울리는 목소리를 자동으로 고릅니다. 끝나면 pick.html(목소리 고르기 화면)이
   열립니다. ▶ 미리 듣기로 들어 보고 바꾸고 싶으면 목록에서 고른 뒤 "캐스팅표 저장"을 누르세요.
2) 2_samples.bat
   역할마다 첫 대사 1줄씩 만들어 pick.html에서 들려 줍니다(약 700크레딧). 마음에 들 때까지
   1)의 화면에서 바꾸고 2)를 다시 실행하세요. 바꾼 역할만 다시 만듭니다.
3) 3_record_main.bat
   먼저 중요한 대사 209줄(캐릭터 대사, 이야기 첫 장면, 약 5,000크레딧)을 만듭니다.
   게임에서 들어 보고 괜찮으면 4)로 넘어가세요.
4) 4_record_rest.bat
   나머지 대사를 모두 만듭니다(약 8,900크레딧, 인터넷 속도에 따라 20~40분). 중간에 꺼져도 다시
   실행하면 이미 만든 줄은 건너뛰고 이어서 만듭니다. 끝나면 hangul_voices.zip이 생깁니다.
5) hangul_voices.zip을 Claude 대화에 올리세요. (또는 Claude에게 "녹음 키트 폴더를 열어 줘"라고
   하면, 데스크톱 앱이 연결된 경우 폴더 접근을 요청해서 직접 가져갑니다.)
   Claude가 용량을 줄이고(아이패드 저장 공간), 게임에 연결하고, 화면 글자와 맞는지 확인합니다.

자주 생기는 일
--------------
- "Windows의 PC 보호" 창이 뜨면: 추가 정보 → 실행.
- "API 키가 맞지 않아요(401)": key.txt에 키만 정확히 들어 있는지 확인하세요.
- "크레딧이 부족해요(402)": 이미 만든 파일은 그대로 있습니다. 크레딧이 생기면 3) 또는 4)를 다시 실행하세요.
- 5_status.bat: 남은 줄 수와 필요한 크레딧을 보여 줍니다.
- 목소리를 직접 고치고 싶으면 casting.csv를 엑셀로 열어 voice_id(voices.csv에 있는 목록), 속도
  (0.5~2.0), 높낮이(-12~12), 감정(smart=문맥에 맞게 자동, 또는 normal/happy/sad/angry/whisper/
  toneup/tonedown)을 바꿉니다. 바꾼 역할의 대사만 다시 만들어집니다.

파일 설명
---------
typecast.ps1   실제로 일하는 스크립트 (PowerShell)
lines.csv      만들 대사 599줄 (파일명, 역할, 대사, 앞뒤 대사)
roles.csv      역할 29개와 원하는 목소리(성별, 나이, 속도, 높낮이)
casting.csv    역할마다 고른 목소리 (1_voices.bat이 만듭니다)
voices.csv     Typecast 목소리 목록 (1_voices.bat이 만듭니다)
pick.html      목소리 고르기 화면
out\           만든 MP3 파일

# 이미지 및 모험 코스 업데이트

기존 WebP 이미지 94개를 개선본으로 교체했습니다. NPC 기본·걱정·기쁨 15장, 상점 주인과 흑묘 전신 2장을 추가했습니다.

한글 섬 지도와 모험 코스 숲 배경을 새로 제작했습니다. 코스에서는 배경, 구름, 빛 입자가 서로 다른 속도로 움직입니다. 토끼 영웅은 8칸 달리기 시트를 사용합니다. 다른 영웅은 전신 이미지의 방향·점프·착지 변화로 표시되며 별도의 달리기 시트는 아직 없습니다. 3D 느낌의 2D 게임이며 실제 3D 모델 게임은 아닙니다.

## 조작과 학습

- 모험 코스: 화면의 좌우 버튼 또는 방향키로 이동, 점프 버튼 또는 스페이스로 점프.
- 자동 달리기 버튼으로 보조 이동을 켜거나 끕니다. 쉬움 모드에서는 글자 블록을 눌러 자동으로 접근할 수도 있습니다.
- 소리에 맞는 글자 블록을 찾으면 자음·모음 조합 문제를 풉니다.
- 도착하면 낱말 읽기, 마지막 글자 채우기, 듣고 낱말 찾기를 복습합니다.
- 문제를 푸는 동안 이동은 멈추며 시간 제한이 없습니다. 오답은 다시 듣고 풀 수 있고 기존 글자 학습 기록에 반영됩니다.
- 기본 낱말 선택과 기존 스테이지 잠금 해제 규칙은 유지했습니다.

## 이미지 제작 기준

내장 이미지 생성으로 기존 캐릭터의 동물 종류, 색, 의상과 정체성을 보존하며 재질·조명·해상도를 높였습니다. 저해상도 악당 카드는 전신 기준 이미지를 추가해 보정했습니다. 게임에는 WebP로 변환하여 포함했습니다.

배경 프롬프트: 어린이용 고품질 3D 애니메이션 스타일, 울창한 숲·푸른 산·폭포·따뜻한 햇빛, 캐릭터와 글자 블록을 위한 중앙 공간, 글자와 UI 없는 횡스크롤 파노라마. 섬 지도는 기존 8개 스테이지의 해변·숲·강·언덕·동굴·광산·절벽·항구 위치를 기준으로 제작했습니다.

달리기 시트 프롬프트: 토끼 영웅의 흰 털·분홍 하트 갑옷·고글 유지, 오른쪽 측면 달리기 8프레임, 4열×2행, 같은 크기와 기준선, 투명 배경.

Jua 한글 글꼴과 OFL 라이선스를 포함해 네트워크 없이도 한글을 표시합니다. 음성은 기기의 한국어 음성 지원에 따라 달라집니다.

## 검증

원본 이미지 94개 전부 변경 확인. 모바일 이동·점프·학습 정지·오답 재시도·문 열기·복습 완료 성공. 새 이미지 로딩 성공. 동화책 1권 모바일 전체 진행과 사건 12개 전체 진행 성공, 페이지 오류 없음.

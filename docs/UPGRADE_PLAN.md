# 전권 완독 후 심화 학습 방안 (설계 문서 — 아직 구현 안 함)

작성: 2026-10-30 · 대상: 12권을 다 읽은 아이(받침 포함 읽기 가능, 만 5세) · 목표: **더 어려운 글 읽기**와 **깊은 이해**로 한 단계 올리기.

> 이 문서는 생각 정리용입니다. 어떤 것도 아직 게임에 들어가지 않았습니다. 보호자가 고르면 그때 구현합니다.

## 0. 설계 원칙

- **같은 세계, 새 난이도**: 새 게임을 또 만들기보다, 아이가 이미 아는 12권·영웅·악당묘를 그대로 쓰고 글만 어려워진다. (아이는 익숙한 이야기에서 더 어려운 글을 견딥니다.)
- **엔진 재사용**: 책 글·질문·배틀 문제는 전부 데이터(books/bN/book.js, CSV)라서, 아래 방안 대부분은 **글만 새로 쓰면** 돌아갑니다. 큰 코드 작업이 필요한 항목은 표에 따로 표시.
- **녹음 정책 유지**: 새 글에는 새 녹음이 필요합니다. 구현 전에 권별·인물별 대본을 먼저 뽑아 드리고, 녹음이 없는 줄은 글로만 나옵니다.

## 1. 방안 목록

### A. 깊이 읽기 모드 (완독한 책에 "별 넷째 칸"이 열림) — 추천 1순위
완독한 권을 다시 열면 "깊이 읽기" 선택지가 생긴다. 같은 이야기를 **긴 글 판**으로 다시 읽는다.

- 문장이 길어지고 복문이 된다. 예) 1권 지금: "거북이는 천천히 걸어요." → 심화: "토끼가 그늘에서 잠든 사이에도, 거북이는 쉬지 않고 한 걸음씩 걸었어요."
- 기록(단서) 글이 2~3문장으로 늘고, 시간·이유 표현(~하는 동안, ~때문에, 그래서)이 들어간다.
- 질문이 사실 확인에서 **추론·감정**으로 올라간다. 예) "토끼는 왜 낮잠을 잤을까요?" / "진 토끼는 어떤 마음이었을까요?" — 지금의 선택지 구조(qs/ev) 그대로.
- 구현 난이도: **낮음** (글 데이터만 추가, 난이도 토글 1개). 녹음: 권당 약 25~35줄 추가.

### B. 어려운 낱말 사전 + 낱말 도감 연동
각 권에서 어려운 낱말 6~8개(게으름뱅이, 동아줄, 배달, 양치기, 그림자…)를 골라, 읽다가 그 낱말을 누르면 뜻·그림·예문 카드가 뜬다. 모은 낱말은 기존 **낱말 도감**에 "책 낱말" 칸으로 쌓인다.

- 수집 요소(도감 채우기)가 있어 완독 뒤에도 다시 읽을 이유가 생긴다.
- 구현 난이도: **중간** (낱말 카드 UI + 도감 칸 추가). 녹음: 낱말+예문 약 90~100줄.

### C. 소리 내어 읽기 측정 (유창성 기록)
이미 있는 마이크 읽기(pgRec)를 확장해, "기록 읽기" 페이지를 소리 내어 읽으면 **분당 글자 수·정확도**를 조용히 기록하고 부모 주간 요약에 그래프로 보여 준다. 아이 화면에는 점수 대신 "또박또박 읽었어요!" 칭찬만.

- 유창성(목표 지표)을 숫자로 추적할 수 있는 유일한 방안.
- 구현 난이도: **중간** (측정·저장·요약 그래프). 녹음: 불필요. 주의: 기기 음성 인식 품질에 따라 오차 있음 — 추세용으로만.

### D. 순서·요약 놀이 확장 (이야기 구조 공부)
지금 3장면 순서 맞추기를 완독 책에서는 **5장면**으로 늘리고, 끝에 "이 이야기를 한 문장으로 하면?" 요약 고르기(3지선다)를 붙인다. 틀린 요약은 그럴듯하게(세부는 맞지만 중심이 아닌 문장).

- 이해 교육에서 효과가 좋은 '중심 생각 고르기'를 게임화.
- 구현 난이도: **낮음~중간** (페이지 5장은 그림 2장씩 추가 필요). 녹음: 권당 약 10줄.

### E. 내 결말 "말로 짓기"
지금은 결말을 고르기만 한다. 심화판: 뼈대 문장을 고른 뒤 빈칸 2개(누가/어떻게)를 낱말 카드로 채우고, 완성 문장을 **아이가 소리 내어 읽어** 녹음하면 결말 영화에 아이 목소리가 들어간다.

- 읽기→말하기→(나중에) 쓰기로 이어지는 다리. 아이가 제일 좋아할 가능성 높음.
- 구현 난이도: **중간** (녹음 저장·재생). 기기 마이크만 쓰므로 Typecast 불필요.

### F. 틀린 글자 탐정 (맞춤법 배틀)
악당묘가 글자를 살짝 바꾼 문장을 보여 준다: "토끼가 낯잠을 자요." → 틀린 글자(낯)를 찾아 고치면 승리. 지금의 문장 고치기·OX 배틀 구조 재사용.

- 받침·비슷한 글자(ㅐ/ㅔ, ㄴ/ㅇ 받침 등) 구분 훈련. 받아쓰기 전 단계.
- 구현 난이도: **낮음** (문제 데이터만). 녹음: 선택(문장은 글로만 둬도 됨).

### G. 두 글 비교 읽기 (상급)
짧은 글 두 개(예: 토끼의 일기 vs 거북이의 일기)를 읽고 "누가 쓴 걸까?" "둘이 다르게 기억하는 건?"을 고른다. 같은 사건을 다른 눈으로 보는 훈련.

- 5세에게는 도전적 — 12권 심화까지 끝낸 뒤 마지막 단계로.
- 구현 난이도: **중간** (새 화면 1개). 녹음: 권당 약 15줄.

## 2. 추천 순서 (로드맵)

| 단계 | 내용 | 이유 |
|---|---|---|
| 1차 | **A 깊이 읽기** + **F 틀린 글자 탐정** | 코드 작업이 가장 적고, "어렵게 읽기"라는 목표에 바로 맞음 |
| 2차 | **B 낱말 사전** + **D 순서·요약 확장** | 이해·어휘를 넓히고 수집 재미 추가 |
| 3차 | **C 유창성 측정** + **E 말로 짓기** | 측정과 표현 — 효과는 크지만 손이 더 감 |
| 4차 | **G 비교 읽기** | 최상급 마무리 |

## 3. 녹음 예산 참고

Typecast 무료 15,000자/월 기준: A안 전권은 약 2.5~3만 자(두 달 분량), F안은 녹음 없이 가능. 1차를 두 달에 나눠 녹음하거나, A안을 6권씩 두 번에 나누는 것을 권합니다.

## 4. 하지 않기로 한 것 (검토 후 제외)

- **새 책 13~24권 추가**: 글 난이도를 올리는 게 목표라면, 새 이야기보다 아는 이야기의 심화판이 학습 효율·제작비 모두 낫다.
- **문법 용어 교육**(주어/서술어 등): 5~6세에는 용어 없이 문장 고치기로 충분.
- **타자/쓰기 입력**: 터치 기기에서 한글 타자는 아직 무리 — E안(말로 짓기)이 그 자리를 대신.

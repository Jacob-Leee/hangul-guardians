# 아이패드·아이폰 실기기 점검표 (v29.4)

컴퓨터의 자동 테스트(크롬 엔진)로는 확인할 수 없는 것만 모았습니다. 아이패드(또는 아이폰) Safari에서 한 번 확인하고, 안 되는 항목은 번호와 함께 알려 주세요. 아이폰 전용 항목은 H7–H9입니다.

- 점검 날짜:
- 아이패드·아이폰 모델 / iPadOS·iOS 버전:
- 한국어 목소리 수: 설정 → 목소리 비교 아래 숫자

## A. 설치와 실행

- [ ] A1. Safari에서 https://jacob-leee.github.io/hangul-guardians/ 를 열면 첫 화면 포스터와 Jua 글꼴이 정상으로 보인다.
- [ ] A2. 1~2분 뒤 설정 → 📲 앱에 "오프라인 사용 준비 완료 ✓"가 나온다.
- [ ] A3. 공유(□↑) → 홈 화면에 추가 → 아이콘이 호랑이 그림, 이름이 "한글 수비대"로 나온다.
- [ ] A4. 아이콘으로 실행하면 주소창이 없고, 맨 위 시계·배터리 줄이 화면 위쪽 버튼을 가리지 않는다.
- [ ] A5. 비행기 모드를 켜고 앱을 실행해도 첫 화면, 도서관, 동화책 그림, 사건 그림, 배경음악이 나온다.
- [ ] A6. 가로·세로로 돌려도 화면이 잘리거나 겹치지 않는다.

## B. 소리

- [ ] B1. 화면을 한 번 누른(손을 뗀) 뒤 배경음악이 나온다. 안 나오면 설정 → 🔊 소리 확인을 누르고 옆에 뜨는 글을 알려 주세요.
- [ ] B2. 무음 스위치나 제어 센터의 무음을 켠 상태에서도 소리가 나온다. 나오지 않으면 무음을 끄고 사용하세요.
- [ ] B3. 🔊 읽어 주기를 누르면 한국어로 읽는다.
  - 더 자연스러운 목소리: 설정 → 손쉬운 사용 → 읽기 및 말하기(콘텐츠 말하기) → 음성 → 한국어에서 '향상된 음성'을 내려받으세요.
- [ ] B4. 목소리가 나오는 동안 배경음악이 작아진다.
- [ ] B5. 홈 화면으로 나갔다가 돌아오면 소리가 다시 나온다.
- [ ] B6. 놀이터·모험 코스·연습 배틀·동화책·사건 수사대에서 각각 다른 배경음악이 나온다.

## C. 읽기 기능

- [ ] C1. 기본 읽기 도움은 3단계 '혼자 읽기'다. 사건과 동화책의 긴 글이 저절로 읽히지 않고, 캐릭터의 짧은 대사는 들린다.
- [ ] C2. 사건 1개를 하는 동안 읽기 미션이 3번 나온다. 글자가 충분히 크고, 낱말을 누르면 그 낱말만 읽어 준다.
- [ ] C3. "다 읽었어요"를 누르면 그림 고르기 문제가 나온다. 틀리면 다시 고를 수 있고, 맞히면 다음으로 넘어간다.
- [ ] C4. 읽기 도움을 2단계로 바꾸면 12초쯤 뒤 🔊 버튼이 반짝인다.
- [ ] C5. 오늘의 모험 '한 바퀴'(게임 8개 + 미션 3개 + 낱말 5개)에서 게임이 끝날 때마다 카드로 돌아오고, 모두 끝내면 축하 화면이 한 번 나온다. 맨 위 ☀️ 표시가 n/10에서 ✓로 바뀐다.
- [ ] C6. 설정 → 글자 실력표 맨 위 '이번 주'에 오늘 막대와 미션 수치가 보인다.

## D. 마이크 (실험 기능)

- [ ] D1. 설정에 "🎤 소리 내어 읽기 확인 (실험)" 항목이 보인다. iPadOS·Safari 버전에 따라 없을 수 있습니다.
- [ ] D2. 켜고 미션에서 🎤를 누르면 마이크 권한을 묻고, 바르게 읽으면 "잘 읽었어요! 🎉"가 나온다.
- [ ] D3. 권한을 거부하면 🎤 버튼이 사라지고, 게임은 그대로 진행된다.

## E. 저장과 백업

- [ ] E1. 앱을 완전히 닫았다(앱 전환기에서 위로 밀기) 다시 열어도 진행이 남아 있다.
- [ ] E2. 설정 → 진행 백업 → 백업 코드 만들기 → 복사한 코드를 메모 앱에 붙여 넣을 수 있다.
- [ ] E3. (선택) Safari 탭에서 코드로 불러오기를 두 번 누르면, 같은 진행 상태로 다시 시작한다.

## F. 업데이트

- [ ] F1. 새 버전을 올린 뒤 앱을 열면 "새 버전이 준비됐어요"가 나오고, 업데이트를 누르면 다시 시작한다.

## G. 터치

- [ ] G1. 버튼을 빠르게 두 번 눌러도 화면이 확대되지 않는다.
- [ ] G2. 글자를 길게 눌러도 복사 메뉴가 뜨지 않는다. 백업 코드 칸은 예외로 복사 메뉴가 떠야 한다.
- [ ] G3. 화면 끝에서 당겨도 화면 전체가 고무줄처럼 튕기지 않는다.
- [ ] G4. 사건의 '현장 조사'에서 반짝이가 모두 보이고, 영웅이 반짝이를 가리면 옆으로 비켜서거나 잠시 화면 밖으로 나간다(가로·세로 모두).
- [ ] G5. 설정 → 🛠 그림 위치 고치기를 켜고 현장 조사를 열면, 반짝이를 손가락으로 끌어 옮길 수 있다. 화면이 같이 스크롤되지 않고, 옮기는 동안 단서로 열리지 않는다. '배치 코드 복사'를 누르면 메모 앱에 붙여 넣을 수 있다. '끝내기'를 누르면 원래 게임으로 돌아온다.

## H. 새 화면과 그림 (v29.3)

- [ ] H1. 첫 화면과 놀이터·낱말 도감의 이모지가 모두 같은 3D 그림으로 보이고, 깨진 네모나 빈칸이 없다. 인터넷을 끄고 다시 열어도 그림이 보인다.
- [ ] H2. 첫 화면 맨 위에 큰 '오늘의 모험' 버튼과 '다음: …'이 보이고, '➕ 더보기'를 누르면 모험 코스·연습 배틀·상점이 나온다.
- [ ] H3. 메뉴(설정)를 누르면 덧셈 문제가 나오고, 숫자 패드로 답을 넣으면 설정이 열린다. 10분 안에 다시 누르면 바로 열린다.
- [ ] H4. 사건 1·2·4–11의 현장 조사에서 새 배경 그림이 보이고, 반짝이가 그림 속 물건(문 앞, 덤불, 우체통 등) 위에 있다.
- [ ] H5. 도서관 두 번째 칸 〈시골 쥐와 도시 쥐〉가 열리고, 처음부터 끝까지 진행된다. 쥐들이 잘리지 않고 보인다.
- [ ] H6. 모험 코스에서 '?' 블록 대신 초록 책 구슬, 끝에 깃발 대신 책 문이 보이고, 책 문에 들어가면 코스가 끝난다.

## H-2. 아이폰과 새 책 입장 (v29.4)

아이폰에서도 Safari로 같은 주소를 열고 홈 화면에 추가해 확인합니다.

- [ ] H7. 아이폰 세로: 동화책의 '추리'와 '순서' 단계에서 기록 카드·책장 카드가 🔊/도움/나가기 버튼과 겹치지 않는다. 아래로 밀면 카드가 끝까지 보이고, 버튼 줄은 화면 아래에 계속 보인다.
- [ ] H8. 아이폰 가로: 동화책·사건 수사대·연습 배틀이 그림 왼쪽, 질문 오른쪽으로 보이고, 그림 속 두루마리·반짝이가 모두 보이며 누를 수 있다.
- [ ] H9. 책을 펼치고 '책 속으로 들어가기'를 누르면 3D 책이 열리고 책장이 넘어가며 영웅이 뛰어든 뒤 금빛으로 번쩍이고 무대가 나온다(약 3초). 끊기거나 검은 화면에 멈추지 않는다. (설정 → 손쉬운 사용 → 동작 줄이기를 켜면 평면으로 짧게 나온다.)
- [ ] H10. 사건 하나를 끝까지 하면 장면마다 배경이 달라진다: 의뢰(천천히 다가감) → 조사(그림 전체) → 증언(흐리고 어둡게) → 기술(빛줄기) → 추리(코르크 게시판에 단서 사진 3장) → 해결(밝게 반짝임). 화면이 끊기거나 반짝이가 물건에서 어긋나지 않는다.
- [ ] H11. 녹음된 목소리: 1권 도서관에서 거북이 스승님 첫 대사, 놀이터에서 글자 소리(기역, 가 …), 사건 증언이 기기 목소리가 아니라 녹음된 목소리로 나온다. 무음 모드(옆 스위치)를 켜면 소리가 안 날 수 있다. 설정 맨 아래에 "목소리: 대사 584줄은 Typecast로 만든 AI 음성" 줄이 보인다(아티팩트 판은 246줄). 이야기 내레이션도 녹음된 목소리로 나온다.

## H-3. v30.1–v30.2 — 따라 쓰기 · 섬 해님 돌 · 본부 3D 기지 · 낚시/두더지 연출

- [ ] H12. 섬 지도에 노란 **해님 돌 11개**가 보인다. 다음에 할 돌 위에 ☀️가 반짝이고, 첫 돌에 오늘 진행(0/11)이 보인다. 돌을 누르면 주인공이 걸어가서 그 놀이가 바로 열리고, 끝나면 돌에 ✓가 생긴다. '오늘의 모험'이라는 버튼·배너·숫자표는 이제 어디에도 없다. 하루 미션은 **섬의 해님 돌 12개**가 전부이고, 다음 할 돌 위에 ☀️가 반짝인다.
- [ ] H13. 놀이터 ✍️ **따라 쓰기(획순)**: 획마다 ①②③ 번호가 붙고 연필이 순서대로 시범을 보인다. **반짝이는 번호 획부터 차례로** 써야 다음 획이 열리고(순서를 건너뛰면 경고), **모든 획을 다 써야** 성공한다 — 반쪽만 만들고 넘어가지지 않는다. 받침 글자(집·강…)는 ㅈ→ㅣ→ㅂ 순서로 나온다. '✏️ 시범' 버튼으로 다시 보여 줄 수 있다.
- [ ] H14. 글자 낚시: 연잎·나비·가끔 뛰어오르는 물고기가 보이고, 물고기 입에서 공기방울이 올라온다. 3번 연속 맞히면 무지개가 뜬다.
- [ ] H15. 두더지 콩콩: 두더지가 눈을 깜빡이고, 맞히면 흙먼지와 💫이 튀고, 틀리면 팻말이 흔들리며 "메롱~" 한다. 무당벌레·민들레 씨앗이 떠다닌다.
- [ ] H16. 본부를 열면 **둥근 기지**가 비스듬히 보이고 천천히 돈다. 12영웅이 링 위에서 각자 일하고(🔍🏋️🗺️🥕🔭✉️📦🧶📚📯🛡️🍪), 가운데 금빛 단상에 거북이 스승님이 있다. 영웅을 누르면 말풍선, 스승님을 누르면 환영 인사가 들린다.
- [ ] H17. 본부 아래 '방 구경'으로 거실·수사실 등 방에 들어가 보물을 놓을 수 있고, "⬅ 기지"로 둥근 기지로 돌아온다.
- [ ] H18. 놀이터 🪞 **거울 반대말**: 1단계 "누가 더 커요?" 그림 고르기 → 3·4단계 반대말 고르기(크다↔작다) → 5단계 문장 빈칸. 정답이면 오른쪽 거울이 번쩍이며 반대말 짝을 보여 준다.
- [ ] H19. 본부 밤 장식: 달·별똥별·깃발·가로등 불빛·반딧불이 보이고, 바닥 무늬와 점선 테두리가 천천히 돈다.
- [ ] H20. 본부가 **조종실 그림**으로 나오고, 그림이 천천히 흔들리며 창에 구름빛이 흐르고 콘솔이 깜빡인다. 영웅을 누르면 반짝 핑+말풍선이 뜨고, 녹음이 있는 영웅은 목소리가 나온다.
- [ ] H21. 메뉴의 '영웅'을 열면 같은 조종실이 뜨고, 친구를 누르면 출동 포즈 카드+목소리가 나오며 "🚀 이 영웅으로 출동!"으로 바뀐다. 바꾼 뒤 홈 왼쪽 위 아바타가 그 영웅으로 바뀐다.
- [ ] **H22. 출동 장면**: 메뉴→영웅 고르기 → 조종실 그림에서 친구 누르기 → 카드에 그 영웅의 출동 그림이 뜨고 목소리가 나오는지 → "이 영웅으로 출동!" → 전체 화면 출동 연출(번쩍+스피드라인+이름 자막) 뒤 영웅이 바뀌는지
- [ ] **H23. 강제 업데이트**: 메뉴→설정→"📲 앱" 줄 — "지금 새 버전 확인"을 눌러 "지금이 최신 버전이에요"가 뜨는지. 새 버전을 올린 뒤에는 앱을 다시 열면(또는 버튼을 누르면) 묻지 않고 저절로 업데이트되는지 ("물어보고 받기"로 바꾸면 예전처럼 띠가 먼저 뜸)
- [ ] **H24. 놀이터 정리**: 한글 놀이터에 게임이 8개(낚시·짝꿍·기차·빈칸·따라 쓰기·반대말·🏭 조립 공장·📝 받아쓰기)이고 두더지·소나기가 없는지. 각 게임 1단계가 '가·나' 같은 한 글자가 아니라 받침 낱말로 시작하는지
- [ ] **H25. 받아쓰기 — 실제 아이 글씨로**: 아이가 직접 쓴 바른 글씨가 대부분 통과하는지(자꾸 틀렸다고 나오면 어떤 글자였는지 메모). 일부러 꽃→꼿, 곰→공처럼 받침을 바꿔 쓰면 "받침이 ㅅ처럼 보여요" 같은 안내와 함께 탈락하는지. 두 번 틀리면 흐린 그림자가 나오는지
- [ ] **H26. 글자 조립 공장**: 낱말 글자 없이 그림만 나오고, 조각을 넣을 때 오른쪽 창에 글자가 조립돼 보이는지(가→강). 3단계부터 '받침 없음' 조각이 있고, 닭 같은 겹받침은 조각 두 개를 넣는지
- [ ] **H27. 한글 섬 이야기 3단계(소나기)**: 놀이터에서 소나기가 빠져도 이야기 단계에서는 그대로 열리고 끝까지 되는지

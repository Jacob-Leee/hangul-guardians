# 책 3~12권 생산 계획 (v30)

> **✅ 2026-10-30 완료.** 열 권 모두 구현·자동 완주 테스트 통과. 대본 536줄(`docs/voice_pack/scripts/b3..b12/`)·그림 프롬프트(`docs/IMAGE_REQUESTS.md` 6번 절) 전달. 그림·녹음이 오면 갈아끼우기만 하면 됨.

2026-10-30 보호자 요청: "3권부터 12권까지 전체 스토리 할 수 있게. 그림·목소리는 바로 요청할 수 있게 프롬프트·대본으로."
서가에 이미 걸린 제목 그대로 만든다(`BOOKS` 표). 모든 문장은 새로 쓴 우리 문장(출판사 문장 복사 금지), 원작을 몰라도 **게임 속 기록만 읽고** 풀 수 있게.

## 진행 원칙

- **그림**: 권마다 임시 그림(코드 생성 WebP: 장면 색감 + 3D 이모지 배우)으로 **바로 플레이 가능**하게 만들고, 진짜 그림이 `incoming/`으로 오면 같은 파일 이름으로 갈아끼운다. 프롬프트는 `IMAGE_REQUESTS.md` 권별 절.
- **목소리**: 기계음 없음(v29.6). 새 녹음이 올 때까지 미녹음 대사는 글로만. 스승님·시스템 멘트는 **전 권 공통 문구**로 통일해 한 번 녹음으로 10권을 덮는다(아래 공통 멘트). 내레이터·새 등장인물 대사만 권별 신규. 영웅 입장 구호도 공통 1문장("가자! 이야기를 되찾자!") × 12영웅.
- **본부**: 책을 되찾으면 보물 1개(`book_bN`) — 권마다 상징 가구/물건.

## 꼭 지킬 것

- **파일명은 표의 `파일명` 그대로** (예: `b1_007.mp3`). 게임이 파일명으로 대사를 찾아 연결합니다.
- **대사는 한 글자도 바꾸지 않기.** 화면 글자와 목소리가 같아야 아이가 따라 읽을 수 있어요.
- 한 파일에 한 줄. MP3. 배경음악·효과음 없이, 앞뒤 무음은 짧게(0.2초 이하).
- 같은 캐릭터는 처음부터 끝까지 **같은 목소리 설정**으로.
- 우선순위 1부터 만들기. 먼저 아래 **테스트 5줄**로 목소리를 정한 뒤 전체 진행.

## OpenAI API로 한 번에 만들기 (선택)

1. OpenAI API 키 준비 (platform.openai.com, 사용량만큼 과금)
2. 같은 폴더에 `dubbing_b1.csv`, `make_voices.py`를 두고:
```
pip install openai
export OPENAI_API_KEY=sk-...        (윈도우: set OPENAI_API_KEY=sk-...)
PRIORITY=1 python make_voices.py     (우선순위 1만. 전부는 PRIORITY=3)
```
3. `out/` 폴더에 파일명대로 MP3가 생깁니다. 폴더를 ZIP으로 묶어 올려 주세요.

# 캐릭터 대사만 녹음하기 (v29 축소판)

아이가 글을 직접 읽으므로 **내레이터·거북이 스승님 대사는 녹음하지 않고 기기 음성(🔊 누를 때만)**으로 둡니다. 녹음할 것은 캐릭터 대사 **157줄, 3,489자**뿐입니다.

- 파일 이름은 전체 대본(`dubbing_b1.csv`, `dubbing_cases.csv`)과 같습니다. 녹음 파일을 `audio/` 폴더에 넣고 `python tools/make_voice_manifest.py`를 실행하면 게임이 자동으로 씁니다.
- 녹음이 없는 줄은 지금처럼 기기 음성이 읽습니다. 몇 줄만 먼저 넣어도 됩니다.
- 거북이 스승님 대사(42줄)는 선택입니다. 스승님 목소리를 살리고 싶을 때만 전체 대본에서 `mentor` 줄을 녹음하세요.
